# MI Operations Hub

A responsive marketing intelligence operations workspace built with Next.js App Router, TypeScript, Tailwind CSS, and shadcn/ui conventions.

## Getting started

Install Node.js 20.9 or later, then install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the dashboard.

## Routes

- `/` Dashboard
- `/deliverables` Deliverables
- `/calendar` Calendar
- `/knowledge-base` Knowledge Base
- `/admin` Admin

## Scripts

- `npm run dev` starts the local development server
- `npm run build` creates a production build
- `npm run start` serves the production build
- `npm run lint` runs ESLint
- `npm run typecheck` runs TypeScript checks
